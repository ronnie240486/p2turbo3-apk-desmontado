# Infinitus 3.1 — Fundo preto e build leve

Esta versão usa novamente o APK funcional `ImperioPlay-HomeLoopFix.apk` como base. O player, os dois DEX, as bibliotecas nativas e a integração Rencia foram preservados. A personalização foi limitada ao nome `Infinitus`, ao logo com fundo preto e aos ícones compactos com fundo preto.

Os assets foram redimensionados para as densidades Android originais, em vez de usar imagens quadradas de alta resolução em todas as pastas. Isso reduz o peso dos recursos e evita a lentidão introduzida pela versão anterior.
