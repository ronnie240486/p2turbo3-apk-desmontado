## Validações

O nome exibido foi confirmado pelo `aapt` como `Infinitus`. A atividade inicial continua sendo `com.legacy.prime.activity.LoginActivity.LoginActivity`. Os ícones `ic_launcher` foram empacotados para `mdpi`, `hdpi`, `xhdpi`, `xxhdpi` e `xxxhdpi`. A assinatura foi verificada nos esquemas v1, v2 e v3.

O hash do `classes.dex` do APK Infinitus é idêntico ao hash do DEX do APK fornecido. A versão anterior que apresentou crash tinha um DEX diferente porque o bytecode havia sido reassemblado; esta release usa o DEX original copiado diretamente durante a reconstrução limpa.
